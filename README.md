# Supermarket Sales & Customer Behaviour Analytics

## Project Overview

This project uses Microsoft Power BI to analyse supermarket
sales and customer purchasing behaviour.

The dashboard provides insights into revenue, transactions,
product categories, branches, payment methods and customer ratings.

## Objectives

- Analyse overall supermarket revenue.
- Compare sales performance across branches.
- Identify the highest-revenue product categories.
- Understand customer purchasing behaviour.
- Analyse payment method preferences.
- Explore monthly sales trends.
- Evaluate customer ratings.
- Build an interactive Power BI dashboard.

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV Dataset
- GitHub

## Dataset

The dataset contains 1,000 transactions and 17 columns.

It includes transaction dates, branch information, product
categories, customer types, gender, payment methods, quantity,
sales amounts, gross income and customer ratings.

Dataset source:

https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales

## Key Performance Indicators

- Total Revenue
- Total Transactions
- Average Order Value
- Total Quantity Sold
- Total Gross Income
- Average Customer Rating

## Dashboard Features

- Interactive date filters
- Branch and city filters
- Product category analysis
- Revenue trend analysis
- Customer type analysis
- Gender analysis
- Payment method analysis
- Transaction details table

## Key Findings

- Total recorded revenue: 322,966.75
- Total transactions: 1,000
- Average order value: 322.97
- Total quantity sold: 5,510
- Total gross income: 15,379.37
- Average customer rating: approximately 6.97

## Limitations

The dataset covers January to March 2019.
The results describe this dataset and should not be
generalised to all supermarkets.
